# Changesets

Hello and welcome! This folder has been automatically generated by `@changesets/cli`, a build tool that works
with multi-package repos, or single-package repos to help you version and publish your code. You can
find the full documentation for it [in the repository](https://github.com/changesets/changesets)

## Usage

### Adding a changeset

Run `bun run changeset` to create a new changeset. You'll be prompted to:
1. Select the version bump type (patch, minor, major)
2. Write a summary of the changes

### Applying changesets (version bump)

Run `bun run version` to consume all changesets, bump the version in `package.json`, and update `CHANGELOG.md`.

### Tagging a release

Run `bun run release` to build and create a git tag for the current version.
